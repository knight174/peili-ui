# Popup 弹出层

相对锚点弹出的底层浮层能力，供 Select / Dropdown / Tooltip 等复用。

## 基础用法

支持 `click` / `hover` / `focus` / `manual` 触发，默认 Teleport 到 `body`，并支持边界翻转。
